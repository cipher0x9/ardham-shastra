# CONTRIBUTING — Ardham Shastra

Thank you for wanting to help learners master anything. ✨

## Ways to contribute
- **Content:** add mandalas, deepen sections, fix typos, add examples
- **Method:** share how the 7-step playbook helped you in a real domain
- **Proof:** add checklists, evals, artifacts that verify learning
- **Accessibility:** improve offline, mobile, and readability

## Ground rules
1. **English surface only.** Sanskrit terms with English gloss are welcome as flavor.
2. **DO NOT CUT.** This campus only grows. Prefer adding to replacing.
3. **Offline-first.** No CDN, no external fonts, no external JS.
4. **Proof habits.** New content should include RTMA or LICC-style verification.
5. **Brand.** CYPHER0X9 display · cipher0x9 GitHub · linktr.ee/cyphermonkey hub.

## How to submit
1. Fork the repo
2. Create a branch: `git checkout -b my-mandala`
3. Make your changes (additive only)
4. Verify the campus still opens offline in a browser
5. Open a pull request with a clear description

## Code of conduct
Be kind. Be precise. Be a learner. No gatekeeping — this campus is free for everyone, everywhere.
