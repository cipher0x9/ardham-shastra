# ARDHAM SHASTRA — EVIDENCE REGISTER

Every claim in this campus carries a status: **SOURCE-FAITHFUL** (anchored in a primary source), **BRIDGE** (faithful core + modern framing), or **INVENTION** (our own pedagogical construct, labeled as such). This register is the proof layer — the RTMA/LICC honesty spine of the campus itself.

**Legend**
- 🟢 SOURCE-FAITHFUL — anchored to a named primary source (edition/page or paper)
- 🟡 BRIDGE — faithful to the source's core, framed for modern learners
- 🔵 INVENTION — our construct/analogy; useful but not a claim about history
- Each entry: ID · Claim · Status · Anchor · Confidence · Caveat · Falsifier
