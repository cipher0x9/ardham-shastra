## Why this exists

Almost everyone has felt the ache: *"I want to master this — but where do I start?"*

This campus is the answer. **Ardham Shastra** (అర్థం శాస్త్రం — the science of meaning & understanding) distills 2,500+ years of Indian learning science — Pāṇini's grammar, Nyāya's logic, Vaiśeṣika's maps, Sāṃkhya's layers, the Kerala school's mathematics, the śikṣā tradition's memory arts — fused with modern cognitive science (spacing, recall, interleaving, deliberate practice).

The promise: **there is a method to master anything.** This campus gives you that method — and the proof habits to know you're actually learning.

Sibling voice packs (already free):

If this helps even one person walk from confusion to calm practice, it was worth sharing.

## Get it in 60 seconds

### ⭐ Open the campus

1. Download this repo (green **Code** → **Download ZIP**)
2. Unzip
3. Open **`university/v1-ARDHAM-SHASTRA.html`** in Chrome / Safari / Edge / Firefox

**Works offline. No account. No install.**

### Or clone (builders)

```bash
git clone https://github.com/cipher0x9/ardham-shastra.git
cd ardham-shastra
open university/v1-ARDHAM-SHASTRA.html
```
