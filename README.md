## What this is

A **lifetime mastery operating system**, not a content dump.

v1 was a single 12 MB HTML file generated by Python — a sincere campus that could not be tested, typed, or scheduled honestly. v2 rebuilds the same forty mandalas as a Next.js static app:

- **Śikṣā** — closed-book retrieval before notes
- **Pāṇini** — finite grammars that generate the cases
- **Nyāya** — five-member proofs and named fallacies
- **FSRS-6** — memory scheduling that tracks stability, not vibes
- **RTMA / LICC** — proof habits so you cannot confuse highlighting with knowing

No account. Progress never leaves the browser. `pnpm build` emits a folder you can open forever.

Sibling campuses: [UC Lab Free University](https://github.com/cipher0x9/uc-lab-free-university) · [AI Lab Free University](https://github.com/cipher0x9/ai-lab-free-university)

## Run

```bash
pnpm install
pnpm dev          # http://localhost:3000
pnpm test
pnpm build        # static site → ./out
```

Then open `out/index.html` or serve `out/`.

## How to study (do not skip)

1. Open **Campus** and pick one mandala.
2. Read the core teaching once.
3. On **Retrieve**, write the answer *before* reveal. Rate the retrieval you actually did.
4. Seal the **green gate** with an artifact that exists without you.
5. Hit **Review** daily. The queue is FSRS-6, target 90% retrievability.
6. Use **Path** for the 90-day arc when you apply the method to a live skill.

Deep packs remain in [`curriculum/`](./curriculum/). Architecture: [`ARCHITECTURE.md`](./ARCHITECTURE.md). First steps: [`START-HERE.md`](./START-HERE.md). Evidence: [`EVIDENCE-REGISTER.md`](./EVIDENCE-REGISTER.md).

## Why these methods

| Move | Classical | Empirical (not a vibe) |
|---|---|---|
| Retrieve, then restudy | svādhyāya | Testing effect (Roediger & Karpicke) |
| Expanding then adaptive spacing | re-recitation cycles | Spacing; FSRS-6 over SM-2 |
| Interleave | multi-śāstra study | Contextual interference |
| Productive struggle | tapas | Desirable difficulty (Bjork) |
| Finite rules + exceptions | utsarga / apavāda | Generative grammar as a study format |
| Public proof | pañcāvayava | You cannot grade a feeling |

We do **not** claim Pāṇini invented spaced repetition. Bridges are labeled in the curriculum packs.
